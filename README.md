🎮 Tienda de Videojuegos — Proyecto Web Estático
🧾 Descripción del proyecto

Este proyecto es una página web estática desarrollada con HTML y CSS, que simula una tienda en línea dedicada a la venta de videojuegos.
El objetivo es practicar la estructura, maquetación y diseño responsivo de un sitio web real, sin incluir aún funcionalidades dinámicas o bases de datos.

La web está organizada por secciones principales: página de inicio, categorías, detalles de productos, información sobre la tienda y una página de contacto.

🧱 Estructura del sitio
tienda-videojuegos/
│
├─ index.html             # Página principal (Home)
├─ categories.html        # Listado de categorías
├─ product.html           # Detalle de producto
├─ about.html             # Sección "Sobre nosotros"
├─ contact.html           # Página de contacto
│
├─ /css/                  # Hojas de estilo
│  ├─ base.css            # Colores, tipografías y variables globales
│  ├─ layout.css          # Estructura del sitio (header, footer, grids)
│  └─ components.css      # Botones, tarjetas, componentes reutilizables
│
└─ /img/                  # Imágenes del sitio (logo, banners, productos)

🌐 Secciones principales
🏠 Inicio (index.html)

Banner o hero principal.

Categorías destacadas (PlayStation, Xbox, Nintendo, PC).

Productos recomendados.

Sección de ventajas o promociones.

🧭 Categorías (categories.html)

Cuadrícula con diferentes consolas o tipos de videojuegos.

Enlaces hacia cada tipo de producto.

🎮 Producto (product.html)

Plantilla para mostrar un juego: imagen, descripción, precio, y productos relacionados.

👥 Sobre nosotros (about.html)

Información sobre la tienda, misión, visión y valores.

✉️ Contáctanos (contact.html)

Formulario de contacto básico (nombre, correo, mensaje).

Datos de ubicación o redes sociales.

🎨 Tecnologías utilizadas

HTML5 – estructura y semántica del sitio.

CSS3 – estilos, diseño responsivo y componentes visuales.
